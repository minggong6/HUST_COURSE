## 复习心得

-    这是苯人前两年学习生涯中复习最*酸爽*的一门课程，得益于机械教务的*集中力量办大事*理念，在三天连考了3门课（马原、计算方法、工材）。又由于苯人坚信*二八复习法*：~~即最后20%的时间能复习80%的知识~~（其实就是拖延症），导致有效复习时间几乎只有一天。复习到后半夜~~清晨~~心动过速又过缓，差点坐上红白小车🚑。  
    
-    苯人于1.12下午考完马原，晚饭后打开B站看网课，晚11点满意回寝，第一次打开真题，一道都不会。于是在某软件花费30r买了期末抢救课，惴惴不安地看到3点。第二天早上舍友大胆总结出规律：几年一循环，期末考试有题库。于是剩下的时间全在背真题答案，考场上开始*默写*，最后90整过关（不要模仿！**他人若学我，如同入魔道**）  
    
-    言归正传，这门课内容难，背诵多。但期末考试题型较传统，题目重叠程度比肩科目一题库。时间充裕可从PPT以及网课入手，总结常考知识点，然后狂刷真题。当你把手上有的真题都看一遍，基本就稳了。考试时间充裕的情况下，尽量给大题配个图（哪怕写错了也可以偷点分）
-    考试顺利！
